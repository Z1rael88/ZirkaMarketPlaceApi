In order to install project, You would need :
- .NET 8.0 SDK
- PostgreSQL (pgAdmin 4)
- Entity Framework installed Globally (dotnet tool install --global dotnet-ef)
- Update Database before run (dotnet ef database update --context ApplicationDbContext --startup-project ../Presentation)
- Run inside your favourite IDE (please... NOT VISUAL STUDIO OR VISUAL STUDIO CODE FOR GOD'S SAKE)
